This R code provides tools for computing the Functional Gait Deviation Index (FGDI), a novel index for quantifying gait pathology using multivariate functional principal component analysis (MFPCA). FGDI addresses limitations of traditional indices such as the Gait Deviation Index (GDI) and Gait Profile Score (GPS) by accounting for the intrinsic smoothness of gait trajectories and the co-variation between joints and planes. The package supports analysis at the level of both legs combined, individual legs, and individual joints/planes. It includes functions for functional data preprocessing, MFPCA decomposition, FGDI computation, and visualisation of abnormality scores, enabling clinicians and researchers to more accurately assess gait abnormalities and track clinical progress or intervention outcomes. 

See Minhas, S. K., Sangeux, M., Polak, J., & Carey, M. (2025). The functional gait deviation index. Journal of Applied Statistics, 1-21. for an overview.
